# سفر المزامير — Digital Psalms Platform

مكتبة رقمية ثابتة (static, offline-first) لقراءة المزامير والاستماع إليها وحفظها ومراجعتها.
بدون خادم، بدون حساب مستخدم، وبدون أى إرسال لبياناتك خارج جهازك.

---

## ⚠️ حالة المشروع ومصدر البيانات — اقرأ هذا أولًا

نص المزامير مُستخرج من ملف PDF مرفق (ترجمة دير الأنبا مقار، ١٥١ مزمورًا بحسب الترقيم السبعينى).

**قبل النشر الفعلى، يجب معرفة التالى:**

- الخط المستخدم فى ملف الـ PDF المصدر غير قياسى، ويتسبب فى تشوّه بعض علامات
  التشكيل (الحركات) عند الاستخراج البرمجى للنص — تظهر أحيانًا حروف زائدة
  (مثل "ر" أو "ه") فى أماكن حركات إعرابية. هذا تم توثيقه ولم يُصحَّح تلقائيًا
  لأن ذلك قد يعنى تغيير كلمات فعلية من النص المقدّس دون تأكد.
- تم إصلاح خلل رقمى واحد فقط، تلقائيًا وبثقة تامة: بعض أرقام الآيات كانت
  تُستخرج بالرقم "١" بدلًا من "٠" (خطأ استخراج معروف)، مما تسبب فى تكرار
  رقم آية بدلًا من رقم آخر. تم تصحيح هذا اعتمادًا على الترتيب التسلسلى فقط
  (لم يُغيَّر أى نص). راجع `data/numbering-corrections.json` لكل تصحيح تم تطبيقه.
- **التوصية:** قبل اعتماد هذا كمرجع نهائى، يُنصح بمراجعة بشرية لنص عدد من
  المزامير مقابل النسخة المطبوعة، أو استبدال `data/psalms.json` بنص نظيف
  إن توفّر لديك مصدر رقمى أدق.

تشغيل `node scripts/validate-data.js` فى أى وقت يعيد توليد تقرير تحقق كامل
فى `data/validation-report.json` (تسلسل، تكرار، حقول ناقصة... إلخ — تحقق
بنيوى فقط، لا يتحقق من دقة الترجمة).

## المزايا المُنفَّذة

- **قراءة**: مكتبة كاملة بـ ١٥١ مزمورًا، صفحة قراءة بتصميم مريح، بحث فورى
  (بالرقم، بالعنوان، بالنص، أو `23:4` للانتقال المباشر لآية).
- **الحفظ**: أوضاع متعددة — قراءة كاملة، كلمات مفقودة (٣ مستويات صعوبة)،
  إكمال الآية، التذكر (Recall)، بطاقات تعليمية (Flashcards).
- **المراجعة**: نظام توصية محلى بسيط (يشبه التكرار المتباعد) يعتمد على
  الإتقان المسجَّل وتاريخ آخر مراجعة — كل الحساب يتم على الجهاز.
- **التخصيص على مستوى الآية**: مفضلة، حفظ، وسم للمراجعة، ملاحظات شخصية —
  لا شىء من هذا يُعدِّل النص الأصلى.
- **الصوت**: مشغّل صوت كامل (تشغيل/إيقاف/سرعة/تقديم)، بنية جاهزة لمزامنة
  إبراز الآية مع الصوت إن وُجدت ملفات توقيت (`timings`)، وواجهة واضحة تقول
  "الصوت غير متاح حاليًا" حين لا يوجد ملف صوتى.
- **النطق الآلى (بديل عند عدم وجود صوت مُسجَّل)**: عند عدم توفر ملف صوتى
  للمزمور، يظهر زر "استماع بالنطق الآلى" يستخدم SpeechSynthesis المدمجة فى
  المتصفح لقراءة النص بصوت اصطناعى. يعمل غالبًا بدون إنترنت إن كان نظام
  التشغيل يحتوى صوتًا عربيًا مثبَّتًا محليًا؛ بعض المتصفحات قد تحتاج اتصالًا
  لتحميل الصوت أول مرة. الجودة تعتمد كليًا على الصوت المتاح فى جهاز المستخدم.
- **التسميع الصوتى (تجريبى)**: فى صفحة الحفظ، وضع "التسميع الصوتى 🎙" يستخدم
  SpeechRecognition لسماع المستخدم وهو يُسمِّع الآية من حفظه، ثم يقارن
  النص المسموع بالنص الأصلى (بعد تجريد الحركات) ويعطى نتيجة صح/خطأ تقريبية
  بنسبة تطابق، وتُسجَّل النتيجة مباشرة فى بيانات الإتقان (نفس مكان بيانات
  الحفظ بالكتابة) بحيث تظهر فى "المراجعة" و"مزاميرى".
  **تنبيه مهم**: هذه الميزة تختلف عن باقى الموقع فى نقطتين: (١) تحتاج عادةً
  اتصالًا بالإنترنت لأن أغلب المتصفحات (Chrome/Edge) ترسل الصوت لخدمة سحابية
  لتحويله لنص — فهى **ليست** جزءًا من وعد العمل بدون إنترنت الخاص بباقى
  الموقع. (٢) الدعم محدود فى المتصفحات؛ تعمل بشكل جيد على Chrome/Edge، وغير
  مدعومة أو ضعيفة الدعم فى Firefox وSafari — الموقع يكتشف عدم الدعم ويعرض
  رسالة واضحة بدلًا من كسر الصفحة.
- **أوضاع القراءة**: وضع القراءة (تقليل التشتيت)، ووضع الصلاة (شاشة داكنة
  مبسّطة جدًا).
- **المظاهر**: فاتح، داكن، ورقى، هادئ — محفوظة محليًا.
- **رحلتى**: إحصاءات القراءة، السلسلة اليومية (streak)، أكثر المزامير عودة،
  خطط قراءة (٣٠/٦٠/٩٠ يومًا).
- **PWA**: قابل للتثبيت، Service Worker بذاكرة تخزين مؤقت لقشرة التطبيق
  وبيانات المزامير، مع تحميل كسول للصوت (لا يُخزَّن أى ملف صوتى إلا بعد تشغيله).
- **تصدير/استيراد بياناتى**: ملف JSON واحد يحتوى كل تقدُّمك، قابل للنقل بين
  الأجهزة.
- **إتاحة (Accessibility)**: تنقّل بالكيبورد، تركيز مرئى، ARIA حيث يلزم،
  دعم `prefers-reduced-motion`.

## ما لم يُنفَّذ بالكامل / نقاط امتداد مستقبلية

- ملفات الصوت الفعلية غير مرفقة (المجلد `audio/` فارغ) — البنية جاهزة لإضافتها.
- بيانات توقيت الصوت (`timings`) غير موجودة لأى مزمور — يمكن إضافتها لاحقًا
  فى `data/psalms.json` دون تعديل الكود.
- خط "Amiri" يُحمَّل حاليًا من Google Fonts (CDN)؛ للعمل بدون إنترنت من أول
  زيارة تمامًا، يُنصح باستضافة ملفات الخط محليًا فى `assets/fonts/`.
- لا يوجد اختبار آلى شامل (unit/e2e) — تم إجراء فحص ثابت (syntax check +
  تدقيق تطابق الـ IDs والـ classes بين HTML/CSS/JS) بدلًا من اختبار متصفح حى.

## التقنية

HTML5 + CSS3 + Vanilla JS (ES6+)، بدون أى إطار عمل، بدون خادم. localStorage
للتفضيلات الخفيفة، IndexedDB للبيانات البنيوية (الإتقان، الملاحظات، سجل
المراجعة).

## إضافة الصوت — واحد بواحد أو دفعة كاملة

**طريقة واحدة بواحد:** من لوحة التحكم → تبويب "الصوت" → اختر المزمور وارفع الملف.

**طريقة دفعة كاملة (١٥١ ملف مرة واحدة):** لو عندك مجلد فيه ملفات مرقّمة `1.mp3` إلى `151.mp3`
(أو مرقّمة بأصفار `001.mp3`)، استخدم سكريبت الرفع الدفعى بدل الرفع اليدوى:

```bash
cd server
node scripts/bulk-upload-audio.js "/path/to/your/audio-folder"
```

لو السيرفر شغّال على رابط مختلف عن `localhost:3000` (مثلًا استضافة فعلية):

```bash
node scripts/bulk-upload-audio.js "/path/to/your/audio-folder" https://your-app.onrender.com
```

السكريبت بيسجّل دخول بنفس بيانات `ADMIN_USERNAME`/`ADMIN_PASSWORD` الموجودة فى `.env`، وبيرفع كل
ملف موجود، وفى الآخر بيوريك تقرير: كام ملف اترفع بنجاح، وأى أرقام مزامير من غير ملف فى المجلد.


## التطوير محليًا

لا يحتاج المشروع أى أدوات بناء. يكفى تشغيل خادم ستاتيك بسيط:

```bash
python3 -m http.server 8000
# أو
npx serve .
```

للتحقق من سلامة البيانات:

```bash
node scripts/validate-data.js
```

## النشر

يعمل مباشرة على أى استضافة ستاتيك — لا حاجة لأى إعداد خاص:

- **GitHub Pages**: ادفع المجلد إلى فرع `gh-pages` أو فعِّل Pages من إعدادات
  المستودع مباشرة على الفرع الرئيسى.

  (Build command: لا يوجد، Publish directory: `.`).

## إضافة اختيارية: لوحة تحكم أدمن (باك إند)

الموقع يعمل بالكامل بدون أى خادم كما هو موضّح أعلاه. لمن يريد لوحة تحكم لتعديل النصوص ورفع
الصوت من مكان واحد بدلًا من تعديل `data/psalms.json` يدويًا، أضفنا باك إند اختيارى بسيط
(أدمن واحد فقط، بدون حسابات للزوار، بدون قاعدة بيانات منفصلة — ملفات JSON عادية للسهولة).

راجع `server/README-BACKEND.md` للتفاصيل الكاملة: الإعداد المحلى، خطوات النشر على Render،
وما الذى يمكن للأدمن التحكم فيه بالضبط.
